# AI护照 · 解闷阅读（v1.1.0）

蹲厕时读约 3 分钟的个性化中文短文，读完就起身。本玩法在分支 `feature/bathroom-short-read`，发布 tag 为 `v1.1.0-bathroom-short-read`。

## 刷机文件

验证通过后：

`build/FoloToy-AI-Passport-full.bin`（整片从 `0x0` 写入）

未授权刷机前请自行确认目标设备。合并镜像可能重置 NVS（含 Wi‑Fi / API Key）。


## 刷机后不自动重启？

AI护照走 **USB-Serial/JTAG**。部分网页刷机工具默认 `hard-reset`（依赖 RTS），在 C3 上可能只回到下载模式而不跑应用，看起来像「刷完没重启」。

- 可先 **拔电再开机**（一定能进应用）。
- 若工具支持，把写完后的动作改成 **`watchdog-reset`**（esptool：`--after watchdog-reset`）。
- 这与本玩法固件内容无关；官方/本仓用 esptool 且 after-reset 正确时应能自动起来。

## 配网与配置页

本版采用 **SoftAP 热点 + 网页配置**（未接微信小程序 BLUFI；后续可再改）。

1. 开机后若尚未保存 Wi‑Fi：屏幕提示配网，手机连接热点 **`AIPassport-XXXX`**（XXXX 为 MAC 后缀）。
2. 浏览器打开 **`http://192.168.4.1/`**。
3. 填写：
   - 最多 3 个 2.4 GHz Wi‑Fi（Wi‑Fi 1 / 2 / 3 的名称和密码）。已保存的名称会填回输入框；密码框不预填，留空则保留该组原密码。只填空格表示无密码网络。空着的名称会跳过，只填一个也可以。
   - DeepSeek API Key
   - 偏好提示词（喜欢读什么）
   - 可选模型，默认 `deepseek-chat`
4. 点保存才写入。手机自动弹出的探测页不会被当成保存。设备会立刻断开当前连接，从 Wi‑Fi 1 开始按 1 → 2 → 3 尝试已填写的网络（空位跳过），连上一个就停止，不用双击 OK 睡眠再唤醒。首次配网成功后会自动拉取一篇短文，屏幕提示「设置修改完成，正在更新内容」。已经有短文后再保存（换 Wi‑Fi、改密码、断网后重配）只连接网络，不自动换文，避免盖掉正在读的内容；要换一篇请长按 OK。只有全部已填网络都连不上时，屏幕才提示「Wi‑Fi 连不上」，热点仍开着，可马上再改，不会停在「正在更新内容」。
   联网成功后屏幕显示局域网 IP；之后可在同一 Wi‑Fi 下用 **`http://设备IP/`** 再改配置。

断网后会防抖片刻再开 SoftAP；已保存的网络按同样顺序后台重试（SoftAP 开着时大约每 8 秒一次），连上后自动关热点并恢复局域网配置页。Wi‑Fi 1 仍写在原来的 NVS 键 `ssid` / `pass`，Wi‑Fi 2、3 使用 `ssid2` / `pass2` 与 `ssid3` / `pass3`，旧固件只配过一组时仍能读出。

**请勿在日志或截图里暴露 API Key。**

## 配置页调试记录

同一配置页（SoftAP 与局域网，地址 `/`，无需登录）底部有两个只读框。顺序是**新的在前**。两条都有内容时，中间空一行。还没有记录时显示「暂无」。

1. **调试：最近系统提示词** — 最近两次实际发给 DeepSeek 的 `role:system` 正文（偏好、避开话题、种子都已写进正文）。这是模型看到的文字，不是整段 JSON。
2. **调试：最近 LLM 原文** — 最近两次从接口解析出的助手原文，发生在去掉 `##题目##` 之前。

第 3 条会覆盖最旧的一条。两组记录重启后仍在，NVS 命名空间为 `toilet`：

| 键 | 类型 | 最大长度（含结尾 NUL） |
| --- | --- | --- |
| `spi` | u8 | 提示词环（`count<<2 \| 最新槽位`） |
| `sp0`、`sp1` | 字符串 | 2048 字节 |
| `lri` | u8 | 原文环，编码相同 |
| `lr0`、`lr1` | blob | 8192 字节 |

提示词用 NVS 字符串（短于单页约 4000 字节的上限）。原文用 blob，才能放下整篇解析结果。64 KiB 的 NVS 分区仍留给短文和 Wi‑Fi：两篇满长度原文加短文大约占 16 页里的 9 页；更新时先写入新 blob，再擦掉旧的。

超过预算时用 `…[截断]` 截断，不让拉取失败。提示词保留开头（标记在末尾）。原文保留结尾（标记在开头），这样 `##题目##` 还在。正常提示词约 1.4 KB，会整段保存。若解析时 8192 字节的正文缓冲在结束引号之前被填满，存下的原文以该标记结尾。若 NVS 报空间不足，原文会再按 4096、然后 2048 字节重试，仍然保留结尾。请求 JSON 一旦拼好就保存系统提示词，即使 HTTPS 在收到正文之前失败。原文只在解析出助手内容之后保存。

## 按键

| 操作 | 作用 |
| --- | --- |
| 上 / 下 | 翻页 |
| 长按 OK | 冷却外：询问「是否获取新内容」；冷却内：提示还剩 x 分钟 |
| 任意键（弹窗） | 关闭提示（确认拉取框内短按 OK 仍确认） |
| 上键（弹窗时） | 关闭弹窗 |
| 双击 OK | 深度睡眠 |
| 任意功能键 | 从深度睡眠唤醒（应用重启） |
| 电源键 | 硬件开关机；睡眠中不要长按 |

## 其它行为

- 目标短文约 1000–1200 字；成功拉取覆盖旧文并写时间戳。
- 每 30 分钟最多成功拉取 1 次；x 为真实剩余分钟（向上取整）。
- 顶部：左 Wi‑Fi 状态，中亮屏时长 `分:秒`，右时钟（联网后 SNTP）。
- 亮屏约 5 分钟提醒一次起身；10 分钟无操作自动深度睡眠。
- 开机 / 亮屏 **不会** 自动拉取。


## 中文显示

正文使用 `font_toilet_20`（约 20px）、状态栏用 `font_toilet_14`；同为 PLAIN 4bpp/2bpp 子集（ASCII + 常用标点 + 一二级字）。无白卡片，正文浅色字画在青绿背景上；分页按行高整行换页，不裁半行。仅首次配网成功会提示「设置修改完成，正在更新内容」并自动拉取。之后保存配置不再自动拉取。源码中文由 `tests/test_toilet_font_coverage.py` 门禁；字库外的 LLM 生僻字仍可能方框。
