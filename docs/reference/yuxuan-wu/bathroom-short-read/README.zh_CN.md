# AI护照 · 解闷阅读（v1.1.0）

蹲厕时读约 3 分钟的个性化中文短文，读完就起身。本玩法在分支 `feature/bathroom-short-read`，发布 tag 为 `v1.1.0-bathroom-short-read`。

## 刷机文件

验证通过后：

`build/FoloToy-AI-Passport-full.bin`（整片从 `0x0` 写入）

未授权刷机前请自行确认目标设备。合并镜像可能重置 NVS（含 Wi‑Fi / API Key）。


## 刷机后不自动重启？

AI护照走 **USB-Serial/JTAG**。部分网页刷机工具默认 `hard-reset`（依赖 RTS），在 C3 上可能只回到下载模式而不跑应用，看起来像「刷完没重启」。

- 可先 **拔电再开机**（一定能进应用）。
- 若工具支持，把写完后的动作改成 **`watchdog-reset`**（esptool：`--after watchdog-reset`）。
- 这与本玩法固件内容无关；官方/本仓用 esptool 且 after-reset 正确时应能自动起来。

## 配网与配置页

本版采用 **SoftAP 热点 + 网页配置**（未接微信小程序 BLUFI；后续可再改）。

1. 开机后若尚未保存 Wi‑Fi：屏幕提示配网，手机连接热点 **`AIPassport-XXXX`**（XXXX 为 MAC 后缀）。
2. 浏览器打开 **`http://192.168.4.1/`**。
3. 填写：
   - 最多 3 个 2.4 GHz Wi‑Fi（Wi‑Fi 1 / 2 / 3 的名称和密码）。已保存的名称会填回输入框；密码框不预填，留空则保留该组原密码。只填空格表示无密码网络。空着的名称会跳过，只填一个也可以。
   - DeepSeek API Key
   - 偏好提示词（喜欢读什么）
   - 可选模型，默认 `deepseek-chat`
4. 点保存才写入。手机自动弹出的探测页不会被当成保存。设备会立刻断开当前连接，先扫描周围网络，只连接扫描里能看到的已保存名称：若上次连上的那一组仍在范围内，优先连它，其余可见的按 Wi‑Fi 1 → 2 → 3。扫描里没有的名称不会去空等超时，所以离开旧网络后保存新的，能马上连上新的那组。不用双击 OK 睡眠再唤醒。首次配网成功后会自动拉取一篇短文，屏幕提示「设置修改完成，正在更新内容」。已经有短文后再保存（换 Wi‑Fi、改密码、断网后重配）只连接网络，不自动换文，避免盖掉正在读的内容；要换一篇请长按 OK。刚保存的网络在扫描里一个都看不到，或每个可见的都连失败时，屏幕提示「Wi‑Fi 连不上」，热点仍开着，可马上再改，不会停在「正在更新内容」。后台仍会继续扫描。
   联网成功后屏幕显示局域网 IP；之后可在同一 Wi‑Fi 下用 **`http://设备IP/`** 再改配置。

断网后会防抖片刻再开 SoftAP，并提示「网络断开」。短时间闪断会先重试当前这个可见网络，不会立刻换组。之后仍只扫描并连接已保存且当前可见的网络（SoftAP 开着时大约每 8 秒扫一次），连上后自动关热点并恢复局域网配置页。上次成功的组号记在 NVS 键 `wpref`（1–3），深度睡眠唤醒后仍优先尝试；还没有成功记录时，可见网络按 1 → 2 → 3。隐藏 SSID 不会出现在扫描里，因此不会被连接。Wi‑Fi 1 仍写在原来的 NVS 键 `ssid` / `pass`，Wi‑Fi 2、3 使用 `ssid2` / `pass2` 与 `ssid3` / `pass3`，旧固件只配过一组时仍能读出。旧固件会忽略 `wpref`。

**请勿在日志或截图里暴露 API Key。**

## 按键

| 操作 | 作用 |
| --- | --- |
| 上 / 下 | 翻页 |
| 长按 OK | 冷却外：询问「是否获取新内容」；冷却内：提示还剩 x 分钟 |
| 任意键（弹窗） | 关闭提示（确认拉取框内短按 OK 仍确认） |
| 上键（弹窗时） | 关闭弹窗 |
| 双击 OK | 深度睡眠 |
| 任意功能键 | 从深度睡眠唤醒（应用重启） |
| 电源键 | 硬件开关机；睡眠中不要长按 |

## 其它行为

- 目标短文约 1000–1200 字；成功拉取覆盖旧文并写时间戳。
- 每 30 分钟最多成功拉取 1 次；x 为真实剩余分钟（向上取整）。
- 顶部：左 Wi‑Fi 状态，中亮屏时长 `分:秒`，右时钟（联网后 SNTP）。
- 亮屏约 5 分钟提醒一次起身；10 分钟无操作自动深度睡眠。
- 开机 / 亮屏 **不会** 自动拉取。


## 中文显示

正文使用 `font_toilet_20`（约 20px）、状态栏用 `font_toilet_14`；同为 PLAIN 4bpp/2bpp 子集（ASCII + 常用标点 + 一二级字）。无白卡片，正文浅色字画在青绿背景上；分页按行高整行换页，不裁半行。仅首次配网成功会提示「设置修改完成，正在更新内容」并自动拉取。之后保存配置不再自动拉取。源码中文由 `tests/test_toilet_font_coverage.py` 门禁；字库外的 LLM 生僻字仍可能方框。
